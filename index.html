Built & verified

  1. AI automation · Python · SMTP & IMAP

    A cold-outreach engine that proves each email actually left

    The sender behind the agency’s own outbound. A pre-flight duplicate gate checks the SQLite log before anything is queued, every SMTP stage is recorded, and the stored Message-ID is read back out of the database after each send — so “sent” is a record, not a print statement. Attachments are hashed before the MIME part is built, the warm-up cap is enforced in code, and a matching IMAP watcher files each reply against the lead that earned it.

    Python · 683 lines · SQLite send log · dry-run against a local SMTP sink before a real inbox

  2. AI automation · Python · yt-dlp & ffmpeg

    One long video in, three captioned vertical clips out

    A clipper built for the short-form side of the business: hand it a YouTube URL and it returns 9:16 clips with captions burned on the frame — yt-dlp fetches, faster-whisper transcribes on CPU, ffmpeg cuts, reframes and burns the cues. Proved on two public sources, a 13-minute and a 10-minute 1080p video, three clips each in 125.6 s and 117.9 s of wall-clock. Both known defects — a caption baseline that collides with baked-in lower thirds, and a centre crop that loses the edges of screen recordings — are written down next to the code rather than left for a client to discover.

    Python · 627 lines · 1080×1920 at 30 fps · audio and burned-in captions verified on the exported files

  3. AI agent stack · local models

    A guard that sits between the model and the machine

    Tool-calling is where a small local model does the most damage: it calls something that does not exist, or returns an empty result that reads exactly like “nothing found”. The guard validates every call against a JSON schema before it executes, keeps a failed tool distinguishable from an empty one, and ships with the terminal output each port actually produced — Node and Python, run against a local Qwen and DeepSeek bench.

    Node.js & Python · JSON-schema validation · run transcripts kept with the code
